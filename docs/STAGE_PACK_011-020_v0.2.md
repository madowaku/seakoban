# SEAKOBAN Stage Pack 011–020 v0.2

## 狙い
Stage 006 の「箱がないと止まれない！」という体験をさらに育てる。新しい海流や特殊箱は追加せず、**漂流・荷物ブレーキ・係留だけ**で、仮置き、再利用、順序を発見させる。

盤面: 5×5 / P=船 / A–D=浮遊荷物 / o=係留地点 / .=海。荷物は他の箱または端に当たる直前まで漂流し、ゴールは通過する。ゴールで停止した箱は固定され、以後はブレーキになる。

番号は行優先で 0〜24、各面の座標は `src/levels.js` を正とする。

## 意図と制約

- Stage 011〜015: 3箱。単純なゴール順より、一時停止位置を重視。
- Stage 016〜020: 4箱。ブレーキの相互依存が増える。
- ゴールの上を通過しても係留されない。
- 係留した荷物は固定されるが、停止用の障害物として使える。
- ターン制ロジックは変えず、漂流速度の差は演出のみに留める。
- 001〜010 の面・ゲームルール・保存キーを変更しない。

**検証:** 探索で全10面に解答を確認し、最短解の荷物ブレーキ回数を集計。実装後は `npm test` と `npm run validate` を実行。**人間が実際に遊んだ難度評価とA401OP実機検証は未実施**。特に Stage 015 の後半および Stage 020 の移動数が長すぎないかを確認する。

## 最初の試遊で聞くこと

1. Stage 011〜013 は、「倉庫番の続き」ではなく「ブレーキの計画」になっているか。
2. Stage 015 は解けたとき気持ちいいか、それとも箱が混んで見えるか。
3. Stage 016 の4箱化は自然か。
4. Stage 020 は41移動に見合う発見があるか。長さだけなら作り直す。
